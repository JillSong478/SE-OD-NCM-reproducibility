SE-OD-NCM Reproducibility Materials

This repository provides extended methodological and reproducibility materials associated with the manuscript:

“A thalamocortical neural mass model of stage-specific discharge patterns and oxygen-deficit burden in status epilepticus”

The accompanying document includes the complete mathematical formulation, detailed parameter settings and initial conditions, parameter-space classification procedures, quantitative comparison with an independent rat pilocarpine-SE dataset, sensitivity and numerical robustness analyses, and model-based intervention analyses.

Essential model specifications and analyses are summarized in Appendix A of the manuscript. The materials provided here are intended as an extended resource for methodological transparency and reproducibility.
