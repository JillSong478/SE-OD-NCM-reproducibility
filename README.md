# SE-OD-NCM Reproducibility Materials

This repository provides MATLAB simulation and analysis code, model parameter settings, and extended methodological materials for the manuscript:

**A thalamocortical neural mass model of stage-specific discharge patterns and oxygen-deficit burden in status epilepticus**

The model combines thalamocortical neural population dynamics, KCC2-dependent chloride regulation, NMDA-mediated excitation, and oxygen-coupled ionic homeostasis to investigate SE-like discharge patterns and cumulative oxygen-deficit burden.

## 1. Requirements

- MATLAB R2022a (used for the original analyses).
- Numerical integration is primarily performed using the explicit Euler method with a time step of 0.01 ms.
- Simulation durations, random seeds, and parameter configurations vary by analysis and are described in the manuscript and extended methodological materials.

## 3. Running the Simulations

1. Download or clone the repository.
2. Open MATLAB and set the working directory to the folder containing the scripts.
3. Select the script corresponding to the desired figure or analysis.
4. Set the relevant parameter configuration according to Appendix A and the Extended Methodological and Reproducibility Materials.
5. Run the script to generate the corresponding simulation results.

Some figures are generated by running the same simulation script with different parameter settings. In particular, `try_0515oxygen.m` is used for multiple electrophysiological and oxygen-related simulations.

Random seeds should be set as specified in the corresponding analyses. The parameter-space scans use fixed stochastic inputs for comparisons across parameter combinations.

**Note:** The simulated stage-specific patterns are produced using prescribed parameter configurations rather than through endogenous progression between stages.

## 4. Independent Experimental EEG Dataset

The independent experimental comparison in Fig. 10 uses rat pilocarpine-status-epilepticus recordings from the publicly available Dryad dataset:

**Hyder et al. (2025), EEG Recordings for: Optogenetic stimulation of the dorsal striatum bidirectionally controls seizures.**

Dataset DOI: https://doi.org/10.5061/dryad.f7m0cfz6w

The analysis includes 11 rats, with four EEG channels aggregated within each rat. The experimental recordings do not contain stage- or phenotype-specific Type 1–4 labels.

For the Fig. 10 quantitative comparison, experimental and simulated signals are analyzed using the same k-point nonlinear energy operator (k-NEO) detection procedure. The separate peak-based detection criteria used for model-state classification in Fig. 9 should not be confused with this procedure.

Users reproducing the experimental comparison should obtain the dataset from Dryad and configure local data paths as required by the MATLAB scripts.

## 6. Interpretation and Limitations

The hypoxia index (HI) is a model-based proxy for cumulative oxygen-deficit burden and has not been validated against histological, imaging, or clinical measures of neuronal injury.

The independent experimental comparison provides partial correspondence with established SE recordings rather than phenotype-specific validation.
